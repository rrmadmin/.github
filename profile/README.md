# rrmadmin

Private ecosystem of restorative reproductive medicine (RRM) projects: rrmacademy.org, neofertility.ie, whittaker.ai, rrm.foundation, lunira, plus shared infrastructure (tools, knowledge bases, agents).

This `.github` repo holds **org-shared GitHub Actions workflows** consumed by the rest of the ecosystem. Most repos here are private and used by RRM Admin staff only.
